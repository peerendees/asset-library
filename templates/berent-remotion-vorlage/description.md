# BERENT Remotion-Vorlage

Startprojekt für Videos im BERENT-CI, gehört zum Skill `skills/remotion`. Pro Video
eine Kopie anlegen, `npm i`, `npm run dev`.

Enthält CI-Tokens, lokal eingebundene Schriften (OFL), Taktraster, zwölf
Effekt-Bausteine, acht Beispielszenen (30-s-Teaser, 120 BPM), eine selbst
erzeugte Platzhalter-Musik sowie Skripte zum Erzeugen von Taktspuren und zum
Messen von Tempo und Downbeat echter Musik. Details in `README.md`.

**Versionen:** Remotion 4.0.534 exakt gepinnt (§5.4 „Abhängigkeiten reifen lassen“).

**Herkunft:** Effektsprache abgeleitet aus einer Stilvorlage (Keynote-Teaser
Thomas Völker, 2026) – übernommen wurden Schnitt- und Taktgrammatik, nicht
Gestaltung, Texte oder Musik. Remotion-Muster nach `remotion-dev/skills`.
